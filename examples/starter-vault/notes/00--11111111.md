# 欢迎使用知识工作室

这是一个不含个人资料和版权书籍内容的示例知识库。

## 从这里开始

- 打开 [[01 建立第一个知识点]]，学习一篇笔记的推荐结构。
- 打开 [[02 连接与 AI 上下文]]，了解双链和节省 Token 的方法。
- 在“关系画布”中点击任意节点，把它切换为新的中心主体。

## Markdown 示例

| 能力 | 写法 |
| --- | --- |
| 标题 | `## 标题` |
| 双链 | `[[笔记标题]]` |
| 任务 | `- [ ] 待办事项` |
| 代码 | 使用三个反引号包围 |
