# Security

## Supported release

Security fixes are applied to the latest GitHub Release. The current package
set is tested only with DeepSeek Harness `0.1.2-rc.1` on Windows x64.

## Reporting

Please report suspected vulnerabilities through GitHub's private security
advisory feature. Do not post model keys, Harness tokens, knowledge-base files,
or machine-specific configuration in a public issue.

The installer validates package hashes before mutation, backs up profile files,
and uses the Harness package manager rather than replacing Harness binaries.
