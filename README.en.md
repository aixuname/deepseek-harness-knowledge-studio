# DeepSeek Harness Knowledge Studio

An unofficial, downloadable distribution wrapper for the Knowledge Studio
plugin set used by DeepSeek Harness.

It adds a local Obsidian-style workspace with Markdown notes, wiki links,
backlinks, focused relationship graphs, per-note Excalidraw canvases, images,
and a token-budgeted AI copilot.

## Requirements

- Windows 10/11 x64
- DeepSeek Harness `0.1.2-rc.1`
- PowerShell 5.1+

Download the latest Windows ZIP from GitHub Releases, close Harness, extract
the archive, and run `install.cmd`. Run `uninstall.cmd` to remove the plugin;
notes and canvases are deliberately preserved.

This repository does not contain the Harness application, personal vaults,
books, model credentials, tokens, caches, or the original TypeScript source.
The six compiled archives preserve their package metadata and MIT licenses.
See the Chinese [README](README.md) for complete installation instructions.
